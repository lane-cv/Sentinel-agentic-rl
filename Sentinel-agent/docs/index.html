找到证据 Observe

告警按指纹去重。诊断 Agent 通过 Claude Agent SDK 调用工具，按手册查询 Prometheus 指标和 Jaeger 调用链，也可从 Milvus 检索相似工单。

决定处置 Decide

Pydantic 校验诊断结构。置信度低于默认阈值 0.6 时转人工。信息类事件记录报告，线上操作由钩子核对命令与目标白名单。

验证修复 Verify

修复 Agent 在配置的服务仓库中修改代码、运行构建和回归测试，验证通过后可发起 PR。评测脚本将实际路由与场景预期对照。

本地运行 Python 3.11

在项目根目录安装依赖，复制配置模板并填写模型服务地址、模型名及鉴权信息。

python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp -n .env.example .env

配好模型后，可用这条信息类告警试跑一次。

AIOPS_RAG_ENABLED=0 AIOPS_REMEDIATION_ENABLED=0 \
  python -m agent.run --alert alerts/s6_info.json \
  --json-out reports/s6_info.json
